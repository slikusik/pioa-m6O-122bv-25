## Различия между реализациями
```
In-Memory (оперативная память)
- Данные хранятся только во время работы программы
- При перезапуске все данные теряются

File Database (JSON)
- Данные сохраняются в файле data/students.json
- Данные сохраняются между запусками программы

File Database (CSV)
- Данные сохраняются в файле data/students.csv
- Данные сохраняются между запусками программы
- Формат CSV совместим с Excel и другими табличными редакторами
- Используется разделитель ; для корректного отображения в русском Excel
```

## Реализованный функцианал
```
Create - Создание записи с проверкой уникальности ID и валидацией данных (возраст ≥ 0, пол — только буквы).
Select - Выборка записей по фильтрам (ID, имя, фамилия, возраст, пол).
Update - Обновление полей выбранных записей.
Delete - Удаление записей по фильтрам.

Дополнительные возможности
Sort - Принимает название поля для сортировки (id, first_name, second_name, age, sex), сортирует по возрастанию и убыванию, при указании несуществующего поля выдается ошибку.
Валидация данных — проверка возраста (≥ 0), поля sex (только буквы), уникальность ID.
Выбор хранилища — пользователь может выбрать тип базы данных при запуске программы.
```
## Инструкцию по запуску
```
При запуске программа предложит выбрать тип базы данных:
1. In-memory — данные хранятся в оперативной памяти
2. File database (JSON) — данные сохраняются в JSON-файле
3. File database (CSV) — данные сохраняются в CSV-файле

После выбора типа базы данных откроется меню с возможностями:
1. Добавить запись
2. Показать все записи
3. Найти записи
4. Обновить записи
5. Удалить записи
6. Сортировать записи
0. Выход
```
